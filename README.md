# 🍔 Food Delivery Analytics

A data analytics project focused on analyzing food delivery operations using **Python, SQL, and Power BI**.

## 🔍 What This Project Covers

* Data Cleaning & EDA
* SQL Data Analysis
* Delivery Time Analysis
* Cancellation Analysis
* Traffic & Weather Analysis
* Hourly Order Analysis
* Restaurant & Area Performance
* Power BI Dashboard

## 🛠️ Tools Used

**Python | Pandas | Matplotlib | SQL | MySQL | Power BI | Jupyter Notebook**

## 📊 Key Insights

* Traffic has a strong impact on delivery time.
* Long delivery time is the major cancellation reason.
* Heavy rain shows higher cancellation rates.
* Order demand varies throughout the day.

## 🎯 Objective

To transform food delivery data into useful business insights for better operational and decision-making processes.
